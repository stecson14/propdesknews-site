    How to read this list

    • Price with code. "Checked at checkout" is what our own checkout showed. "Our math" applies the code's stated percent to the list price. The firm's checkout is the final word.
    • Monthly plans renew until you pass. A code marked "first month" only discounts the first charge.
    • Rules. Target, max loss and daily loss appear only where we read them for that exact account; max loss on some 50K rows comes from our rules pages. Everything else links to the full rules.
    • Partners. 27 firms use our affiliate code or link (gold button). We may earn a commission at no cost to you. It does not change the order: the list sorts by price.

    Questions

    What is the cheapest prop firm challenge?

    It depends on the size and on today's codes, so the list sorts by the price you would pay with a code. Set the size you want and the top row is the lowest-cost account we track at that size today, counting the code and any activation fee. Monthly plans charge that price every month until you pass.

    Is the price with the code exact?

    Rows marked "checked at checkout" are what our own checkout showed. Rows marked "our math" apply the code's stated percent to the list price; the firm's checkout is the final word. Activation fees are added only when the firm lists them.

    Why do some accounts say "See rules"?

    We only show a profit target or max loss when we read it for that exact account on the firm's own pages. Where we have not, the row links to the firm's rules or profile page instead of guessing.

    Which prop firms does Prop Desk earn from?

    Rows with a gold Copy code button are firms whose affiliate code or link we use; we may earn a commission at no cost to you. Every other row links to our firm page, not the firm. Sorting and prices are the same for both.

    How we checked

    List prices are read from each firm's own pricing page and re-checked every week; a firm's prices drop off the list after 21 days without a check. Code prices come from our own checkouts and from each code's stated discount. Last built Nov 13, 2026. Edited by Steven T.
